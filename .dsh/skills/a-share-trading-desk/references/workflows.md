# 盘前 / 开盘 / 午间 / 收盘 / 定池 的完整步骤

## 一、07:00 盘前尽调 + 计划

> **为什么是 07:00**：3 只票尽调要 40 分钟，08:30 起步就装不进 09:30 开盘前；
> 而且 07:00 在 DeepSeek 低谷计费档（高峰 09:00–12:00 / 14:00–18:00），成本省一半。

候选来自**前一交易日 15:10 的定池**（3–6 只），这里**不再跑筛子**：从池子里挑 2–3 只跑 LLM 尽调，没覆盖的留到 12:00。规则先决、LLM 只做否决。

**必须实际检索，不能凭记忆。** 找不到就写"未检索到"，**绝不编造消息**。

### 步骤

1. **隔夜外盘**（新浪直连，`Session.trust_env=False`）：

   | 标的 | 新浪代码 |
   |---|---|
   | 纳指100 | `gb_$ndx` |
   | 道指 | `gb_$dji` |
   | 标普500 | `gb_$inx` |
   | 富时A50期货 | `hf_CHA50CFD` |

   `data_sources.quote()` 对美股代码可能返回空，此时直接用
   `https://hq.sinajs.cn/list=<code>` + `Referer: https://finance.sina.com.cn` 手工取。

2. **消息面**：东财 7×24 快讯
   `https://np-weblist.eastmoney.com/comm/web/getFastNewsList`（`pageSize=200`），
   筛出目标日期区间、与稀土/创业板/证监会/央行/中美相关的条目。

3. **持仓定位**：拉现价，算距成本、距止损、距目标。

### 输出结构

1. 周末/隔夜消息清单（3–6 条，**每条带来源与时间**，只写真正影响 A 股的）
2. 隔夜外盘表
3. 动作结论（明确"清/留/加"）
4. `## ⚠️ 需要你下单` + 表格，或"今天不需要下单"
5. 失效条件

### 判读要点

- **区分"个股事件"与"板块/行业事件"**：某只票重组停牌复牌 ≠ 板块利好。
  验证方法：看同板块其它票是否跟涨。只有龙头涨、跟随者不动 → 个股事件，不参与。
- 外盘只提供背景，**不单独构成买卖理由**。

## 二、09:25 开盘执行

读集合竞价价，**按位置分档**：

| 开盘价位置 | 指令 |
|---|---|
| 计划清仓，开盘 ≥ 成本 | 可直接市价清，或挂成本以上限价 |
| 计划清仓，开盘在成本与止损之间 | 按计划清，不要因为想等反弹而拖延 |
| 计划清仓，跳空 < 止损 | 仍按计划清，**不要因为低开就改主意** |
| 计划买入，开盘在买区内 | 挂限价买，数量按 100 股整数倍 |
| 计划买入，开盘已涨出买区 | 不追，等回踩 |

09:25 之后进入**巡检窗口 09:35–11:25**，每 10 分钟一次：持仓看止损/目标，候选看买点是否进入买区，判定规则见 `references/triggers.md`。

## 三、11:30 午盘复筛 + 12:00 午休尽调

### 11:30–12:00 午盘复筛（不调 LLM）

用半日 K 线把候选池重新过一遍，**只做减法**：

1. 跑 `screen_v3.py --stage1-only`（或直接用现价 + 上午高低点复算 MA/量能）。
2. 删掉上午已经走坏的：跌破 MA20、放量下杀、买点失效的标的。
3. 保留 100 股整数倍可买、买区仍在现价附近（±2% 内）的。
4. 输出：留下几只、删掉几只及原因；**最多 3 只**进入下午。

### 12:00–13:00 午休尽调（≤3 只）

- 对象：07:00 没覆盖的、或复筛后新进入的标的，**最多 3 只**。
- 数据：半日 K 线 + 实时价 + 上午消息面；仍走低谷计费档。
- 输出：每只一句话结论（买/观察/放弃）+ 买区/止损/目标；放弃的写清失效条件。
- 13:00 之前必须收口，形成下午唯一的执行清单。

## 四、14:50 收盘前总结

### 必含内容

1. 三大指数涨跌（上证/深成/创业板）
2. 持仓表：现价（14:50，收盘可能略有差异）、涨跌、日内高低、盈亏金额
3. **今日合计**：已实现 + 浮动
4. 账户：现金、总权益、仓位
5. 今天做对了什么（1–3 条，带数字）
6. 明天计划（每只标的的条件与动作）
7. `## ⚠️ 需要你下单` 或"今天不需要下单"

### 记账（顺序固定）

见 SKILL.md §3。

## 五、15:10 收盘定池（明日候选 3–6 只）

> 这一步**只用规则，不调 LLM**。定的是"明天看哪几只"，不是"明天买什么"；尽调留到 07:00 和 12:00。

### 步骤

1. 跑筛选器：
   ```powershell
   .\.venv\Scripts\python.exe screen_v3.py --limit 400 --top 10
   ```
2. 读 `data/logs/screen_v3_<YYYYMMDD>.json`
3. **检查板块约束**（见 SKILL.md §0）——出现 300/301/688/689 立即报警，不写候选池
4. 写候选池 `save_watchlist`：
   - `buyLow = MA20 × 0.995`，`buyHigh = MA20 × 1.02`
   - `stopLoss = MA20 × 0.97`
   - `target = 突破位 × 1.002`
   - `status` 一律 `待触发`（已持仓的标 `持仓`）
5. 池子控制在 **3–6 只**：超过 6 只按总分截断，不足 3 只就如实写"今天没有合格标的"，不要为凑数降门槛。
6. 推飞书（`label="收盘定池"`）：一句结论 + 池内表格 + 漏斗各层数字

### 漏斗结构（screen_v3.py）

| 层 | 内容 | 输出 |
|---|---|---|
| 0 | 板块过滤 + ST/价格 3–60/日均额 ≥3e7/流通市值 ≥3e9 | 候选宇宙 |
| 1 | Weinstein 阶段 + Minervini 趋势模板 8 条件 | 趋势分 /32 |
| 2 | RS 相对强度 + 形态 | RS 分 |
| 3 | 基本面硬门槛：净利同比 ≥+20% **且** 营收同比 ≥+10% | 基本面分 |

**8/8 全过的通常只有 15–25 只，最终过基本面门槛的常只有 0–3 只。这是正常的。**

### 推送模板

```
漏斗：400 只 → N 只过 8/8 → M 只 7/8+ → K 只过基本面硬门槛（另 X 只无数据已剔除）
结论：今天不买 / 可买 X（买区 A–B，止损 C）
```

## 六、分析类请求（用户问"某只票怎么样"）

走 `AGENTS.md` §3 的固定结构：结论 → 数据表 → 依据（技术+资金+消息）→ 动作 → 失效条件。

需要多智能体深度分析时：

```powershell
.\run.cmd --ticker 600111.SS --date 2026-11-12 --analysts market --save --no-show --no-html --no-checkpoint
```

报告落在 `data/logs/reports/<ticker>_<日期>_<时间>/`。
注意：`run.cmd` 正常结束时也可能返回 exit code 1（`cli_prefs.json` 权限问题），**报告照常生成**，不要误判为失败。

## 七、定时任务的维护

| 任务 | rrule 形态 | 说明 |
|---|---|---|
| 盘中巡检 | `FREQ=MINUTELY;INTERVAL=10;UNTIL=<当日14:50>Z` | 只有 09:35–11:25、13:05–14:50 两段；每天重建，不要用跨天 WEEKLY |
| 收盘定池 | `FREQ=WEEKLY;BYDAY=MO,TU,WE,FR`（15:10） | 长期有效 |
| 盘前尽调 | `FREQ=WEEKLY;BYDAY=MO,TU,WE,FR`（07:00） | 长期有效，跑在低谷档 |
| 午盘复筛 / 午休尽调 | `FREQ=WEEKLY;BYDAY=MO,TU,WE,FR`（11:30 / 12:00） | 复筛不调 LLM，尽调 ≤3 只 |

修改用 `schedule_edit`（`action="update"` 或 `"delete"`），**没有 `schedule_update` 这个工具**。
