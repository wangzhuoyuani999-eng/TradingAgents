# A 股交易台操作流程

本工作区是 **A 股实盘跟踪 + TradingAgents 分析**环境。
`AGENTS.md` 已自动加载，规定了输出格式与风控硬约束；本 skill 只补它没写的**工作流**。
两者冲突时，以 `AGENTS.md` 为准。

## 0. 铁律（每次动手前先过一遍）

- **只做沪深主板**：000/001/002/003/600/601/603/605。
  **创业板 300/301、科创板 688/689 买不了（无权限）**；北交所 4/8、B 股 9 开头不做。
  输出里一旦出现 300/301/688/689，说明过滤失效 → **报警，且不要写入候选池**。
- **一天最多买一只。**
- **止损用收盘确认制**：盘中破位不砍，收盘确认后**下一个交易日**执行；跳空跌破则开盘执行。
- **单笔风险 ≤ 总权益 1%**（按止损距离算）；单只 ≤65%；总仓 ≤85%。
- **大盘总开关（2026-11-27 修订，回测背书）**：`上证收盘 > MA20` **或** `> MA200` 才允许开新仓；跌回 MA20 下方即停止开新仓（已持仓不清）。解锁后首笔按**试仓**：1 手、单笔风险 ≤0.5%，次日起转常仓。
- **需要下单时**必须用 `## ⚠️ 需要你下单` + 表格（标的/方向/价格/数量/止损/有效期）；
  不需要就明确写「**今天不需要下单**」。
- 持仓、现金、候选池**以 `data/trading_desk/*.json` 为准**，不要用对话里记的旧数字。

## 1. 每日节奏

| 时点 | 做什么 | 数据 | LLM | 档位 |
|---|---|---|---|---|
| 15:10 | **收盘定池** → 明日候选 3–6 只 | 当日完整 K 线 | 否 | — |
| 07:00 | **盘前尽调 + 计划**（定池里挑 2–3 只） | 外盘 + 昨收 | 是 | 低谷 |
| 09:35–11:25 | **巡检**（持仓止损 + 候选买点复核） | 实时 | 否 | — |
| 11:30–12:00 | **午盘复筛**（半日 K 线，剔走坏的） | 半日 | 否 | — |
| 12:00–13:00 | **午休尽调**（≤3 只，补 07:00 没覆盖的） | 半日 + 实时 | 是 | 低谷 |
| 13:05–14:50 | **下午执行窗口**（按分档下指令） | 实时 | 否 | — |

三条排程原则：

- **选股与尽调分开**：15:10 只跑规则（`screen_v3.py`）定池，不调 LLM；LLM 只在 07:00、12:00 两个低谷档跑，成本省一半、也不占用盘中时间。
- **定池 → 尽调 → 执行的顺序不能反**：15:10 产出 3–6 只，07:00 只对其中 2–3 只做深度尽调（剩下的留到 12:00），09:25 及 13:05 之后只做执行与巡检，不再临时开新标的。
- **巡检窗口**是 09:35–11:25 和 13:05–14:50；11:30–12:00 是复筛、12:00–13:00 是尽调，都属于**计划任务**，不用巡检格式，也不推飞书。

**非交易时段**（15:00 后、11:30–13:00 之间没有计划任务时）巡检只回一句「非交易时段，跳过」，**不推飞书**。

## 3. 交易台读写（文件制，不用插件）

**本工作区不装交易台插件**，没有 `trading_desk_read` / `trading_desk_write`。持仓、现金、候选池全部记在仓库根的 `PORTFOLIO.md`；`data/trading_desk/*.json` 是插件的空壳，**不要再写**。

- 单一事实来源：`PORTFOLIO.md`（`data/` 被 .gitignore 忽略，所以放根目录）；
- 面板：`trading_desk.html` 由 `PORTFOLIO.md` 生成，**改完必须重建**：
  `.venv/Scripts/python.exe tools/build_trading_desk.py`
- 写 `PORTFOLIO.md` 时保留可识别的表头字样（`标的 | 代码 | 数量 | 成本价 | 现价/收盘 | 止损 | 减仓规则 | 目标`；候选池 `标的 | 代码 | 现价 | 买区 | 止损 | 目标 | 状态`），面板按表头名解析。

**成交后的固定顺序**（顺序不能乱）：

0. 每笔成交都写台账：`.venv/Scripts/python.exe tools/trade_log.py add --ticker ... --entry ... --exit ...`（迭代日志要靠「20 笔」触发复盘，不记就等于没启动计数器）
1. 买入成交 → 持仓表加一行（标的 / 代码 / 数量 / 成本价 / 止损 / 目标），账户表扣现金
2. 卖出成交 → 清仓就删行；减仓（≥100 股整手）就改数量、成本价不变
3. 现金变化 → 账户表 `现金` 与 `总权益`
4. 当日复盘 + 次日计划 → `变更记录` 补一行
5. 候选池变动 → 重写「候选池」小节
6. 重建面板 + 推飞书（见 `references/triggers.md` §六）

## 5. 判断口径（别每次都重新发明）

- **趋势优先于便宜**：跌破 MA20 的票不接，MA20 在下移的票不接。
- **买点位置比分数重要**：同分两只票，回踩企稳的 vs 跌破均线继续杀的，只买前者。
- **止损收到保本**是减仓后的默认动作，不是可选项。
- **一天只买一只**是纪律，不是建议——它是多次避免踩雷的主因。
- 候选池长期只有 0–3 只合格标的属于正常，**不要为了出手而降低门槛**。
