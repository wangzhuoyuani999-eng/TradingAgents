# 选股策略迭代日志

> 规则：**每一版都有编号、有证据、有回测背书，旧版本保留可回滚。**
> 版本号格式：主版本.次版本（主版本 = 框架变更，次版本 = 参数调整）

---

## 迭代纪律（先定规则，再谈改进）

1. **触发条件**（满足任一即评估）：
   - 实盘累计 **20 笔**交易；
   - 或每 **一个季度**（3/6/9/12 月末）；
   - 或出现连续 **5 笔亏损**；
   - 或市场状态发生结构性变化（如上证从 MA200 上方转下方持续 20 日）。
2. **变更门槛**：任何参数/规则修改，必须在 **2023-01 至 2026-11** 的同区间、同基准上回测，**收益或回撤至少一项改善 10% 以上**才采纳。
3. **记录要求**：每次变更写清「改了什么 / 为什么 / 证据 / 回滚方式」。
4. **禁止**：因为最近几笔亏钱就改参数（这是过度拟合的开端）；**必须**用样本量说话。

---

## v1.0 — 2026-11-10（基线）

**框架**：温尼斯坦四阶段 + 米内尔维尼趋势模板 8 条 + CANSLIM 的 C/A/L + 大盘 MA200 择时

**参数**：
| 项 | 值 |
|---|---|
| 价格区间 | 3–60 元 |
| 20 日均成交额 | ≥ 1 亿 |
| 趋势模板 | 8 条全过（7 条入池观察） |
| 季净利同比 | ≥ +20% |
| 季营收同比 | ≥ +10% |
| ROE | ≥ 12% |
| 相对强度 | 120 日涨幅全市场分位 |
| 入场 | 60 日新高+1.5 倍量；或回踩 MA20 缩量 |
| 出场 | 收盘破 MA20，或满 20 日 |
| 单笔风险 | 1% 净值 |
| 持仓上限 | 3 只 / 单只 35% |

**回测证据**（2023-01 至 2026-11，市值前 150，3 只上限）：
- 240 笔，胜率 36.7%，平均 +1.03%/笔，PF 1.52
- 累计 +98.2%，最大回撤 −17.4%
- 基准（同池买入持有）+90.1%
- **不加择时对照：最大回撤 −38.0%** → 择时是本版最大贡献

**已知缺口**：
- 回测未使用财务门槛（F10 只有最新一期，无法按公告日对齐）
- 无板块相对强度
- 无实盘样本

## v1.1 — 待办（下一版计划候选）

按优先级：
1. **财务数据时点对齐**（用 `REPORT_DATE` 而不是最新一期）→ 让回测包含基本面层；
2. **板块相对强度**（申万一级 20 日涨幅排名前 20% 才可买）；
3. **财报日过滤**（财报前 3 日不开仓）；
4. **出场优化**：MA20 换成 ATR 跟踪止损，比较回撤。

每项都要单独回测，不能一起改（否则不知道是谁的功劳）。

## 实盘跟踪

实盘每笔交易记录在 `data/logs/strategy_trades.jsonl`，字段：
`ticker / name / entry_date / entry / stop / shares / score / exit_date / exit / ret / reason / system(0-1)`

用 `strategy_stats.py` 统计，与回测基线对比；**偏离阈值**：20 笔后胜率 < 25% 或 PF < 1.1 → 触发复盘。
